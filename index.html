About ShopExplorer

ShopExplorer is a lightweight, vanilla TypeScript showcase that fetches real product data from dummyjson.com/products, rendered entirely on the client. Search, category filtering, sorting and an accessible details modal are built with semantic HTML, modern CSS and strict TypeScript — no frameworks.
